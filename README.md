# اسکنر هوشمند اسناد (Document Scanner)

یک اپلیکیشن کامل، مدرن و امن اسکن و مدیریت اسناد برای اندروید با طراحی Material Design 3، رابط کاربری فارسی و تطابق ۱۰۰ درصدی با قوانین و مقررات Google Play Console و Play Protect.

---

## 🌟 ویژگی‌های کلیدی برنامه (Features)

- 📸 **اسکن هوشمند اسناد (Smart Document Scanning):** پیش‌نمایش زنده دوربین با قابلیت تشخیص خودکار حاشیه کاغذ، کنترل فلش‌لایت و تصویربرداری تک‌برگ یا چندبرگه.
- 🎨 **فیلترهای پردازش تصویر (Image Processing Filters):**
  - **سیاه و سفید (B&W):** بالابردن کنتراست متن برای متون داستانی و اداری.
  - **خاکستری (Grayscale):** حذف رنگ‌های اضافه و حفظ جزئیات سایه‌روشن.
  - **رنگ جادویی (Magic Color):** شفاف‌سازی و زنده‌سازی رنگ‌های مدارک شناسایی و عکس‌ها.
  - **اصلی (Original):** حالت طبیعی تصویر اولیه.
- ✂️ **برش و چرخش هوشمند (Crop & Rotation):** قابلیت برش چهارنقطه‌ای دستی و چرخش ۹۰ درجه صفحات اسکن‌شده.
- 📄 **تولید و خروجی PDF (PDF Generation & Sharing):** تبدیل صفحات اسکن‌شده به فایل PDF با کیفیت بالا و قابلیت اشتراک‌گذاری مستقیم یا ذخیره در دانلودها.
- 📁 **مدیریت و پوشه‌بندی اسناد (Folder Organization):** دسته‌بندی اسناد در پوشه‌ها، جستجوی سریع در نام و محتوای اسناد، و مرتب‌سازی بر اساس تاریخ.
- 🛡️ **حریم خصوصی ۱۰۰٪ محلی (Offline First & Privacy Safe):** بدون نیاز به اینترنت، ذخیره‌سازی کاملاً محلی روی دستگاه، بدون ذخیره یا ارسال داده‌های شخصی.

## 🔑 راهنمای امضای برنامه و ساخت نسخه انتشار (Release APK & AAB)

برای ساخت نسخه رسمی و امضاشده جهت آپلود در **Google Play Console** مراحل زیر را دنبال کنید:

### ۱. ساخت کلید امضا (Keystore)
در محیط ترمینال، دستور زیر را اجرا کنید تا کلید امضا ایجاد شود:
```bash
keytool -genkeypair -v \
  -keystore my-upload-key.jks \
  -keyalg RSA \
  -keysize 2048 \
  -validity 10000 \
  -alias upload
```

### ۲. تنظیم متغیرهای محیطی یا ساخت فایل امضا
می‌توانید متغیرهای محیطی زیر را تنظیم کنید:
```bash
export KEYSTORE_PATH="/path/to/my-upload-key.jks"
export STORE_PASSWORD="your_store_password"
export KEY_ALIAS="upload"
export KEY_PASSWORD="your_key_password"
```

یا فایل `my-upload-key.jks` را در ریشه پروژه قرار دهید. برنامه به‌طور خودکار وجود کلید را بررسی کرده و نسخه انتشار را با آن امضا می‌کند.

### ۳. ساخت فایل Android App Bundle (AAB) برای گوگل پلی
```bash
./gradlew bundleRelease
```
فایل خروجی جهت آپلود در Play Console در مسیر زیر ایجاد می‌شود:
`app/build/outputs/bundle/release/app-release.aab`

### ۴. ساخت فایل APK امضاشده جهت تست مستقیم
```bash
./gradlew assembleRelease
```
فایل خروجی APK در مسیر زیر ایجاد می‌شود:
`app/build/outputs/apk/release/app-release.apk`

## 🏗️ ساختار پروژه (Architecture & Tech Stack)

- **زبان توسعه:** Kotlin
- **رابط کاربری:** Jetpack Compose + Material Design 3
- **معماری:** MVVM + Clean Architecture
- **پایگاه داده محلی:** Room Database (KSP)
- **پردازش تصویر:** Android Canvas & Matrix + ML Kit Text Recognition
- **دوربین:** CameraX API
- **تست:** Robolectric & Roborazzi Visual Testing
